# Readme doc for PH502 practical 06, James Hennessy 27 October 26


## Purpose

- prac_06 initialises 3 arrays, A, B and C
- Computes the elements of C (matrix multiplication of A and B)
- Prints the elements of matrices A, B and C, one row at a time

## Contents
- One file called prac_06.c which can be compiled using gcc.

## How to run

Compile the .c file with the following cmd:

gcc prac_06.c -o name_you_choose

Then run the code using:

./name_you_choose


## Output
- Prints the elements of matrices A, B, and C, one row at a time
